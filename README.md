# Solo OS · 一人公司经营作战室

> 把接单、定价、排期、回款收进一张桌面：录一次，驾驶舱、三档报价、每周作战计划与应收账龄自动算出来。

**在线体验：https://09xc.github.io/** ｜ 单文件 · 零网络依赖 · 无需注册 · 数据只存本地浏览器

## 它解决什么问题

个体创业者、自由职业者、小微工作室主理人，一个人同时做销售、交付、财务和市场。客户散在微信、报价靠拍脑袋、回款靠记忆，结果是 **「做得多、赚得少，还不知道钱去哪了」**。

市面上多数「一人公司工具」是表格模板或聊天框。Solo OS 不新增流程，只把真实接单流程的四道关变成可计算的东西。

## 四道关

| 阶段 | 能力 | 输入 → 输出 |
|---|---|---|
| 01 归档 | 客户与项目台账 | 客户（含来源）、项目金额 / 预估工时 / 交付日 → 可流转的台账 |
| 02 定价 | 三档报价引擎 | 工时、目标时薪、硬成本、风险系数、利润率 → 保守 / 建议 / 上限价 + 折合时薪 + 分期 |
| 03 排期 | 目标倒推作战计划 | 营收目标、周期、客单价、线索成交率 → 每周线索 / 报价 / 交付任务清单 |
| 04 回款 | 应收账龄与现金流 | 交付日 + 已回款 → 逾期标红、回款率、未来 8 周应收分桶 |

首屏是可操作的经营驾驶舱：已回款、应收未收、在办项目、有效时薪、未来 8 周应收柱状图。改任何一个数字，四处联动重算。

## 计算公式（页面内可逐项核对）

```
有效工时 = 预估工时 × (1 + 风险系数)
成本     = 有效工时 × 目标时薪 + 硬成本
建议价   = 成本 ÷ (1 − 目标利润率)
保守价   = 成本 × 1.05        上限价 = 建议价 × 1.25
折合时薪 = (报价 − 硬成本) ÷ 有效工时

需成交 = ⌈目标营收 ÷ 平均客单价⌉
需线索 = ⌈需成交 ÷ 线索成交率⌉
每周线索 = ⌈需线索 ÷ 周数⌉     每周报价 = ⌈需成交 × 报价系数 ÷ 周数⌉

有效时薪 = 已回款累计 ÷ 累计预估工时
应收     = 合同额（非洽谈中） − 已回款
```

## 三分钟看懂（评委动线）

1. 打开链接 → 右上角 **载入示例数据**（4 个客户 / 6 个项目 / 24 条任务）。
2. 首屏驾驶舱：已回款 ¥52,600、应收未收 ¥65,800、在办 4 个、有效时薪 ¥191/h，底部直接提示「1 笔已逾期，共 ¥22,800」。
3. 第二节工时偏差计算器：把实际工时 92 改成 60，看实际时薪与「应该报多少」的变化——这就是「做多赚少」被算出来的瞬间。
4. 第 02 关报价台：风险系数 20%→30%、利润率 25%→35%，三档价、折合时薪、分期与公式行同步变化。
5. 第 04 关回款：给逾期项目登记一笔回款，逾期标记与回款率立即更新。

## 技术说明

- 单文件 HTML（64KB），CSS/JS/图标/图表全部内联，**零网络请求**，双击即可离线使用。
- 数据存 `localStorage`（键 `solo-os:v1`），不上传任何服务器；支持导出 / 导入 JSON 备份。
- 无账号体系，打开即用。
- 无障碍：跳转链接为首个可聚焦元素、全键盘可完成主要操作、可见焦点环、支持 `prefers-reduced-motion`，正文对比度 ≥ 4.5:1。
- 已在 320 / 390 / 768 / 1440 / 1920 / 2560 六档视口实测无横向溢出；33 项交互与状态用例全部通过，控制台 0 报错。

## 边界（诚实说明）

- 数据仅存当前浏览器，换设备 / 清缓存会丢，请用「导出备份」。
- 报价为税前一价制，未含税率、平台抽成、汇率。
- 未来 8 周应收按**交付日**分桶，不代表实际到账日。
- 目标倒推是**四则运算 + 经验系数的规则推演**，不是大模型生成；每个中间量都在页面上。
- 适用 1–3 人的个体经营体；不适用于需要账号权限、发票税务、银行对账的团队。
